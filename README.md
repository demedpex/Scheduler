# 내부망 업무 스케줄러

망분리 내부망에서 도는 엑셀 매크로 스케줄러입니다. 서버도 DB도 공유폴더도 쓰지 않습니다.
파일 하나(`Scheduler.xlsm`)가 프로그램이자 데이터베이스입니다.

## ⚠️ 먼저 알아두실 것 — 무엇이 공유되고 무엇이 안 되나

| 기능 | 저장 위치 | 공유 |
|---|---|---|
| 업무 | 내 PC의 파일 안 | ❌ 나만 봅니다 |
| 유관부서 연락하기 | 내 PC의 파일 안 | ❌ 나만 봅니다 |
| 점심약속 | 내 PC의 파일 안 | ❌ 나만 봅니다 |
| **업무공유** | 내 PC의 파일 안 | ✅ **메신저 텍스트로 주고받습니다** |

공유폴더도 파일첨부도 못 쓰는 환경이라, 업무공유만 **메신저 대화창에 붙여넣는 텍스트**로 오갑니다.
실시간이 아니라 "내보내기 → 붙여넣기 → 상대가 가져오기" 방식입니다.

---

## 1. 설치

### 1-1. 파일 받기

`dist\Scheduler.xlsm` 를 각자 PC의 원하는 폴더에 둡니다. 예: `D:\업무\스케줄러\`

> 팀원마다 각자의 파일을 갖습니다. 같은 파일을 여럿이 여는 방식이 아닙니다.

### 1-2. 신뢰할 수 있는 위치 등록 ★ 팀원 전원 1회 필수

이걸 안 하면 매크로가 차단돼 아무것도 동작하지 않습니다.

```
Excel 실행
 → 파일
 → 옵션
 → 보안 센터
 → [보안 센터 설정...] 버튼
 → 신뢰할 수 있는 위치
 → [새 위치 추가...]
 → Scheduler.xlsm 이 들어 있는 폴더를 선택
 → "이 위치의 하위 폴더도 신뢰함" 체크
 → 확인 → 확인
```

Excel 을 껐다가 다시 켠 뒤 파일을 엽니다.

### 1-3. VBA 프로젝트 개체 모델에 대한 액세스 신뢰

**빌드하는 사람만 필요합니다. 파일을 받아 쓰는 사람은 안 해도 됩니다.**

```
Excel → 파일 → 옵션 → 보안 센터 → [보안 센터 설정...]
 → 매크로 설정
 → "VBA 프로젝트 개체 모델에 대한 액세스 신뢰" 체크
```

## 3. 직원 명부 준비

이름으로 내선번호를 찾으려면 명부가 필요합니다.

1. `sample\직원명부_양식.csv` 를 열어 실제 명부를 채웁니다.

   ```
   이름,내선번호,부서,직급
   홍길동,1234,기획팀,과장
   김영희,02-1234-5678,총무팀,대리
   ```

   - **부서·직급은 비워도 됩니다.** 비어 있어도 전 기능이 동작합니다.
   - 내선번호에 `0212` 처럼 0으로 시작하는 값이 있어도 그대로 보존됩니다.
   - 중간에 완전히 빈 행이 나오면 거기서 읽기를 멈춥니다. 중간에 빈 줄을 두지 마세요.
   - CSV 대신 XLSX 도 됩니다.

2. 채운 파일을 팀에 나눠 줍니다.
3. 각자 `설정` 시트에서 **[명부 갱신]** 을 누르고 그 파일을 고릅니다.
   - 파일 내용을 프로그램 안으로 **복사해 옵니다.** 원본 파일이 없어져도 계속 동작합니다.
   - 명부가 바뀌면 각자 다시 [명부 갱신] 을 누르면 됩니다.
   - 연락하기에는 이름·부서만 저장되고 내선번호는 매번 명부에서 조회합니다.
     그래서 명부를 갱신하면 이미 등록된 연락 건의 전화번호도 자동으로 최신이 됩니다.

## 4. 사용법

### `오늘` 시트

```
 ◀   2026-08-27 (수)   [오늘]  ▶
 [업무 등록] [연락 등록] [점심 등록] [공유 등록] [새로고침]

 ■ 업무
  ☐  월간 보고서 초안        14:00
  ☑  거래처 회신             (완료된 줄은 취소선 + 회색)

 ■ 유관부서 연락하기
  ☐  김지은(기획팀)   내선 1101   10:30

 ■ 업무공유                        [공유 내보내기] [공유 가져오기]
     기획-2026-0451  상반기 실적 보고   D-3   회신기한 08/30   홍길동
```

- **☐ 칸을 한 번 클릭** → 완료/미완료 토글. 완료하면 취소선 + 회색이 됩니다.
- **제목 칸을 한 번 클릭** → 내용 팝업
- **아무 줄이나 더블클릭** → 그 항목 수정
- **◀ ▶** 로 날짜 이동, **[오늘]** 로 복귀
- D-day 는 `D-DAY`(빨강 굵게), `D+2`(빨강, 기한 지남), `D-3`(주황, 임박) 으로 표시됩니다.

### `달력` 시트

```
 ◀   2026년 8월   ▶  [오늘로]
 일    월    화    수    목    금    토
       ...
       27
       업무 3 · 연락 1
       공유 2
```

- 날짜 칸을 클릭하면 `오늘` 시트가 그 날짜로 바뀌며 이동합니다.
- 오늘 칸은 파랗게, 회신기한이 3일 이내인 공유건이 있는 날은 붉게 표시됩니다.

### `설정` 시트

| 항목 | 설명 |
|---|---|
| 내 이름 | 업무공유에 작성자로 기록됩니다 |
| 명부 파일 경로 | 마지막으로 읽은 명부 파일 |
| [명부 갱신] | 명부 파일을 다시 읽어 옵니다 |
| 백업 보관일수 | 기본 30일 |
| 마지막 동기화 시각 | 마지막으로 공유를 가져온 시각 |
| 입력 방식 | `폼` 또는 `패널` (아래 8번 참고) |
| [전체 데이터 내보내기 / 가져오기] | 프로그램을 새 버전으로 옮길 때 쓰는 통로 |
| [백업 지금 실행] | 즉시 백업 |
| [화면 새로고침] | 화면을 다시 그립니다 |

## 5. ★ 업무공유 주고받기

### 보내는 쪽

1. `오늘` 시트에서 **[공유 내보내기]** 클릭
2. 범위를 고릅니다 — `전체` / `내가 등록한 것만` / `최근 N일` / `회신기한 미도래분만`
3. 화면에 `대상 5건 / 조각 3개` 처럼 나옵니다.
4. **[1/3 복사]** 클릭 → 메신저 대화창에 붙여넣기(Ctrl+V) → 전송
5. 버튼이 **[2/3 복사]** 로 바뀝니다. 다시 클릭 → 붙여넣기 → 전송
6. **[3/3 복사]** 까지 반복하면 끝입니다.

> 조각이 1개면 버튼 한 번으로 끝납니다.
> 조각은 메신저 글자수 제한 때문에 나눈 것이고, **레코드 중간에서 자르지 않습니다.**

붙여넣어지는 텍스트는 이런 모양입니다. 사람이 읽으라고 만든 게 아니니 그대로 보내면 됩니다.

```
###WSCH1|P1/3|N=5###
S|홍길동-20260827-143052-8471|기획-2026-0451|상반기 실적 보고|본문 첫줄\n둘째줄|2026-08-27|2026-08-30|홍길동|2026-08-27 14:30:52|0
###END|P1/3|C=A3F1###
```

### 받는 쪽

1. `오늘` 시트에서 **[공유 가져오기]** 클릭
2. 메신저에서 받은 텍스트를 복사해 큰 칸에 **붙여넣기(Ctrl+V)**
3. 붙여넣는 순간 자동으로 읽습니다. 따로 누를 버튼이 없습니다.
   - `2/3 조각까지 받았습니다. 남은 조각 1개(3)를 이어서 붙여넣으세요.`
     → 칸이 자동으로 비워집니다. 다음 조각을 그냥 붙여넣으면 됩니다.
   - **조각 순서는 상관없습니다.** 3 → 1 → 2 로 넣어도 됩니다.
   - **같은 조각을 두 번 넣어도 안전합니다.** 중복으로 들어가지 않습니다.
4. 다 받으면 목록에 `[신규] / [갱신] / [변화없음] / [삭제]` 가 표시됩니다.
5. **[반영]** 클릭 → `신규 3건, 갱신 1건, 변화없음 2건 반영했습니다.`

### 이런 메시지가 나오면

| 메시지 | 뜻 | 할 일 |
|---|---|---|
| 인식할 수 없는 텍스트입니다 | 머리말(`###WSCH1`)이 없음 | 텍스트를 처음부터 끝까지 다 복사했는지 확인 |
| 복사 중 텍스트가 잘렸거나 변형됐습니다 | 체크섬 불일치 | 보낸 사람에게 다시 보내 달라고 요청 |
| 이미 받은 조각입니다 | 같은 조각 재투입 | 남은 조각 번호를 확인해 그것만 넣기 |

### 충돌은 이렇게 처리됩니다

| 상황 | 처리 |
|---|---|
| 서로 다른 건 | ID가 달라 자연히 공존 |
| 같은 건을 두 사람이 수정 | `수정시각`이 최신인 쪽 채택 |
| 한쪽이 삭제, 한쪽이 수정 | **삭제 우선.** 지운 건은 되살아나지 않습니다 |
| 문서번호가 같은데 ID가 다름 | 병합은 하고, 결과 요약에 `문서번호 중복` 으로 알려 줍니다 |

덮어써진 내용은 `log_Merge` 숨김 시트에 남습니다. 나중에 확인할 수 있습니다.

## 6. 백업과 복구

- 파일을 열 때마다 **자동으로** `Scheduler.xlsm 이 있는 폴더\backup\Scheduler_20260827.xlsm` 로 복사됩니다.
- 같은 날 이미 백업이 있으면 건너뜁니다. (하루 1개)
- 보관일수(기본 30일)를 넘긴 백업은 자동으로 지워집니다. `설정` 시트에서 바꿀 수 있습니다.
- VBA 통합 문서는 드물게 손상됩니다. 이건 선택 기능이 아닙니다.

### 복구 방법

1. `backup` 폴더에서 쓸 만한 날짜의 파일을 찾습니다.
2. 그 파일을 상위 폴더로 복사하고 이름을 `Scheduler.xlsm` 으로 바꿉니다.
   (망가진 원본은 `Scheduler_손상.xlsm` 등으로 이름을 바꿔 남겨 두세요.)
3. 엽니다.


`dist\Scheduler.xlsm` 이 만들어집니다. 어느 단계에서 왜 실패했는지 한국어로 출력합니다.

### 한셀로 미리 보기 (테스트 전용)

Excel 이 없는 PC에 한셀만 있을 때, 시트·표 구조를 미리 확인하는 용도입니다.
**배포본을 만드는 용도가 아닙니다.**

```powershell
powershell -ExecutionPolicy Bypass -File build\build.ps1 -Engine hcell
```

`dist\Scheduler_한셀테스트.xlsm` 이 만들어집니다. 배포본(`Scheduler.xlsm`)과 이름이 다릅니다.

한셀에서 확인된 것과 안 되는 것:

한셀 2022(12.0.0.3146)에서 실제로 빌드해 확인한 결과입니다.


`RunAllTests` 는 `tbl_Share` 와 `mst_Employee` 를 잠시 비우고 쓰지만,
시작할 때 통째로 저장해 두고 **오류가 나도 반드시 되돌립니다.**

> `build\*.ps1` 은 반드시 **UTF-8 with BOM** 으로 저장하세요.
> PowerShell 5.1 은 BOM 없는 .ps1 을 CP949 로 읽어서 한글이 전부 깨집니다.

## 8. UserForm 을 만들 수 없는 PC

보안정책으로 "VBA 프로젝트 개체 모델에 대한 액세스 신뢰" 를 켤 수 없으면 빌드가 UserForm 을
만들지 못합니다. 이때는 **입력 화면만 `입력` 시트로 바뀌고 기능은 전부 그대로 씁니다.**

- `설정` 시트의 `입력 방식` 이 `패널` 로 표시됩니다.
- `[업무 등록]` 등을 누르면 숨어 있던 `입력` 시트가 나타나 항목을 입력받습니다.
- `[저장]` / `[취소]` / `[삭제]` / `[명부에서 찾기]` 는 셀을 클릭하면 동작합니다.
- 동명이인 선택은 팝업 대신 번호를 입력받는 창으로 나옵니다.

빌드 자체를 못 돌리는 경우는 `dist\manual_import\읽어보세요.txt` 를 따르세요.
CP949 로 저장된 소스가 들어 있어 VBE 에서 그대로 가져오면 한글이 깨지지 않습니다.

## 9. 알림 기능에 대해

`Application.OnTime` 으로 지정 시각에 팝업을 띄우는 건 가능하지만 **엑셀이 열려 있을 때만** 동작합니다.
엑셀이 꺼져 있어도 알림이 필요하면 Windows 작업 스케줄러로 엑셀을 자동 실행하는 방법이 있는데,
사내 PC 정책 확인이 먼저입니다. **이번 버전에는 구현하지 않았습니다.**

### 데이터가 어디에 있나

`Scheduler.xlsm` 안의 숨김 시트에 표(ListObject) 로 들어 있습니다.

| 표 | 내용 | 동기화 |
|---|---|---|
| `tbl_Task` | 업무 | ❌ |
| `tbl_Contact` | 연락하기 | ❌ |
| `tbl_Share` | 업무공유 | ✅ |
| `tbl_Lunch` | 점심약속 | ❌ |
| `mst_Employee` | 직원 명부 | ❌ |
| `cfg_Setting` | 설정 | ❌ |
| `log_Merge` | 병합 로그 | ❌ |

모든 값은 **문자열로** 저장됩니다. 날짜는 `2026-08-27`, 시간은 `14:30` 형식입니다.
엑셀 날짜 서식이나 지역설정에 휘둘리지 않게 하기 위해서입니다.

ID 는 `홍길동-20260827-143052-8471` 형태입니다. 자동증가 숫자는 PC마다 따로 증가해
반드시 충돌하므로 쓰지 않습니다.

삭제는 물리 삭제를 하지 않고 `삭제여부` 플래그만 켭니다. 이게 지운 항목이 병합 때
되살아나는 걸 막는 유일한 수단입니다.
